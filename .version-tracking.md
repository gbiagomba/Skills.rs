**Bugs found and fixed during implementation**

1. **Rollback compared the wrong digest.** It compared the destination against
   the backup's saved content (`digest_before`), which always differs after a
   successful write, so every legitimate rollback would have been refused. Fixed
   by recording `digest_after` on the backup row via
   `Store::record_backup_result`, called only after the write is verified.
   Caught by `rollback_restores_the_previous_contents`.
2. **Re-running `copy` silently discarded local edits.** `install` treated any
   path with a deployment row as ours to overwrite, so re-installing over an
   edited deployment destroyed the edit, violating the product promise. Fixed by
   splitting the guard into two refusals: never-managed gives exit 11, drifted
   gives exit 3. Caught by a manual smoke test, now pinned by
   `reinstalling_over_a_locally_edited_deployment_refuses_rather_than_discarding`.
3. **`sync` exited 0 on a conflict**, giving a script no signal. Now returns 3
   via `ReconPlan::reject_if_conflicted`, while plain drift stays 0 because
   preserving an edit is sync working as designed.
4. **`thiserror` field collision.** Variants using `source: String` for a source
   locator failed to compile, since `thiserror` reserves `source` for the error
   cause. Renamed to `locator`.
5. **A test asserted the wrong precedence.** `no_baseline_requires_an_explicit_decision`
   expected the no-baseline message for an unmanaged destination, but provenance
   correctly takes precedence over drift. The code was right; the test was fixed
   to exercise both paths.

**Decisions recorded**

- **MSRV is 1.88, not the 1.85 planned.** Transitive `icu_*` and `time` require
  1.88. Verified with `cargo +1.88 check --locked --all-targets`
- `zip` resolved to 7.2.0 and `gix` to 0.87.1 because cargo honours the declared
  MSRV; newer majors need a newer toolchain
- `smb2` 0.27 chosen over `pavao`: pure Rust, no `libsmbclient`. It does pull
  tokio (320 crates with the feature on, 285 without), which is documented
- `SKILL_AGENT_HOME` added. Without it there is no way to test end to end without
  writing into the developer's real agent installation. It is namespaced
  deliberately; `$HOME` is still never honoured for agent roots
- Exit code 12 added for "documented but not implemented in this build"
- Missing frontmatter `name` is a warning plus a Gemini-scoped error, not a hard
  error, because Claude Code and Codex both fall back to the directory name
